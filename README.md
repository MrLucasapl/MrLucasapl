## About me

Software Developer with **4+ years** building and scaling applications end to end. Day to day I design APIs with **Express** or **NestJS**, and I still ship screens when the product needs it — **React**, **Next.js**, and **React Native (Expo)**.

I care about architecture that stays testable: **Clean Architecture**, **DDD**, **Hexagonal Architecture**, dependency injection, and **TDD**. Recent work includes cutting a critical listing API from **4.83s to ~1.32s (~75%)**, putting **BullMQ + Redis** queues in production, and shipping inspection flows with **AI** on **Supabase Edge Functions**.

I also do **code review** and mentor junior developers.
